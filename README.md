# دانشجوی بهاروند — فرم سه‌مرحله‌ای ثبت‌نام (با اتصال به پایگاه داده)

یک سایت شامل فرم سه‌مرحله‌ای (Wizard) + داشبورد نمایش اطلاعات، با بک‌اند Node.js/Express و پایگاه داده SQLite.

## اجرا (روی دبیان / هر لینوکسی)

پیش‌نیاز: Node.js نسخه ۱۸ به بالا (`node -v` را چک کنید).

```bash
./start.sh
```

این اسکریپت خودش پکیج‌ها را نصب می‌کند (فقط بار اول) و سرور را بالا می‌آورد.
بعد از اجرا، در مرورگر بروید به:

```
http://localhost:3000/form.html   → فرم ثبت‌نام
http://localhost:3000/index.html  → داشبورد
```

اگر پورت ۳۰۰۰ اشغال بود:

```bash
PORT=4000 ./start.sh
```

## ساختار پروژه

```
server.js              بک‌اند Express + مدل SQLite
data.sqlite3            فایل پایگاه داده (بعد از اولین اجرا ساخته می‌شود)
public/form.html        فرم سه‌مرحله‌ای
public/index.html       داشبورد نمایش ثبت‌نام‌ها
public/css/style.css    استایل
public/js/form.js       منطق فرم (اعتبارسنجی + ارتباط با API)
public/js/dashboard.js  واکشی و نمایش رکوردها
```

## نحوه‌ی کارکرد

- هر مرحله از فرم با کلیک روی دکمه، به یک endpoint در بک‌اند POST/PUT می‌شود و بلافاصله در SQLite ذخیره می‌شود (نه فقط در پایان).
- مرحله ۱: یک رکورد جدید با `status = step1` ساخته می‌شود.
- مرحله ۲: همان رکورد آپدیت می‌شود، `status = step2`.
- مرحله ۳: رکورد نهایی می‌شود، `status = completed`.
- داشبورد مستقیماً از `GET /api/submissions` همه‌ی رکوردها (کامل و ناقص) را می‌خواند.

## تغییر فیلدهای فرم ۲ و ۳

فیلدهای مرحله ۲ و ۳ را من به‌صورت نمونه (ثبت‌نام پروژه‌ی گیم‌دولوپمنت) طراحی کردم. اگر می‌خواهید فیلدهای دیگری داشته باشد، در سه جا باید هماهنگ تغییر بدهید: `server.js` (ستون‌های جدول و ولیدیشن)، `public/form.html` (فیلدهای HTML)، `public/js/dashboard.js` (نمایش در کارت‌ها).
